# Property Database System

This directory contains the property database files generated by the OLX property extraction tests.

## Database Files

### Main Database Files
- **`property_database.json`** - Main database file containing all extracted property data
- **`property_database.csv`** - CSV version of the database for easy viewing in Excel/Google Sheets
- **`enhanced_property_database.json`** - Enhanced version with metadata (IDs, timestamps, etc.)
- **`property_statistics.json`** - Statistical analysis of the property data

### Historical Files
- **`property_data_YYYY-MM-DDTHH-MM-SS.json`** - Timestamped files for historical tracking

## Data Structure

Each property record contains:
```json
{
  "title": "Property title",
  "price": "Rs 90,000",
  "location": "Bahria Town - Civic Centre, Rawalpindi",
  "floor": "Ground Floor",
  "uploadTime": "15 hours ago",
  "id": "prop_unique_id",
  "extractedAt": "2024-01-15T10:30:00.000Z",
  "source": "OLX Pakistan",
  "dataVersion": "1.0"
}
```

## Usage

### Reading the Database
```javascript
// In Cypress tests
cy.readFile('cypress/fixtures/property_database.json', 'utf8').then((data) => {
  console.log('Total properties:', data.length)
})
```

### Using the Database Utilities
```javascript
import { loadDatabase, savePropertyDatabase, mergeDatabase } from '../../support/database'

// Load existing database
loadDatabase().then((data) => {
  console.log('Loaded', data.length, 'properties')
})

// Save new data
savePropertyDatabase(newPropertyData)

// Merge with existing data
const merged = mergeDatabase(newData, existingData)
```

## Features

- **Location-Specific Files**: Each search location gets its own set of database files
- **URL Source Tracking**: Actual source URLs are stored instead of generic strings
- **Multiple Formats**: Saves data in both JSON and CSV formats
- **Historical Tracking**: Maintains timestamped versions for historical analysis
- **Metadata Enhancement**: Adds unique IDs, extraction timestamps, and source information
- **Statistical Analysis**: Generates comprehensive statistics about the property market
- **Data Validation**: Ensures data quality and completeness

## File Locations

Files are now organized by search location with the following naming convention:

- **Main Database**: `cypress/fixtures/{location}_properties.json`
- **CSV Export**: `cypress/fixtures/{location}_properties.csv`
- **Enhanced Database**: `cypress/fixtures/{location}_enhanced.json`
- **Statistics**: `cypress/fixtures/{location}_statistics.json`
- **Historical Files**: `cypress/fixtures/{location}_{timestamp}.json`

### Example for "Islamabad" search:
- `islamabad_properties.json`
- `islamabad_properties.csv`
- `islamabad_enhanced.json`
- `islamabad_statistics.json`
- `islamabad_2024-01-15T10-30-45-123Z.json`

## Database Operations

The system supports:
- ✅ **Create**: New database from extracted data
- ✅ **Read**: Load existing database
- ✅ **Update**: Merge new data with existing
- ✅ **Delete**: Remove duplicates automatically
- ✅ **Analyze**: Generate statistics and insights
- ✅ **Export**: Multiple formats (JSON, CSV)
- ✅ **Track**: Historical versions with timestamps
